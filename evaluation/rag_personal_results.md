## RAG 구현 상세

### Personal RAG 구성
- 임베딩 텍스트: 거리/페이스/심박/케이던스/고도/칼로리 + 존 이름 포함
- 검색: 코사인 유사도, Top 3 유사 과거 운동
- 컨텍스트 주입 위치: zones + 용어 다음, 운동 데이터 바로 앞
- LLM 지시: "summary 또는 heartrate_analysis에 비교 수치 인용 + progress 필드 요약"

### 1차 시도 대비 개선 사항
1. RAG 지시가 `progress` 필드만 → `summary`/`heartrate_analysis`에 인용하도록 변경
   - judge가 `progress` 필드를 평가하지 않았기 때문
2. `parse_qwen_output`에 `progress` 필드 추가 → judge가 과거 비교 데이터 볼 수 있도록
3. repeat=3으로 채점 안정화 (1차 시도는 repeat=1)
